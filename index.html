What it does

Two jobs: reply to messages you receive, and write the first message to people you find.

✨ Reply in the thread

Click into any LinkedIn message box and an AI Reply button appears above it. It reads the open conversation and drafts a reply into the box. Click again for a different version.

🎯 Goal & voice Ask

The ▾ menu sets the intent: Interested, Ask for details, Politely decline, or Thank — plus an optional one-off Ask you can type or dictate with the 🎤 mic.

📝 Polish your draft

Type a rough draft first, then click AI Reply. Instead of starting over, it refines what you wrote and keeps the facts you put in.

📇 Outreach from profiles

On any profile, a Draft message button fills one of your templates — reach-out, referral ask, application, follow-up and more — word for word for that person.

🧠 Remembers context

It keeps a short recap of your recent exchanges with each person, locally, so replies stay consistent over time. Clear it any time in Settings.

🔌 Your choice of model

Use your Claude subscription via a helper Chrome launches on demand (no API key), or paste an Anthropic or OpenAI API key. Switch any time in Settings.

🔒 Nothing sends itself

The extension only writes text into the box. You always read it, edit it, and press Send. Your API key never leaves your browser; the conversation or profile being drafted is sent to your chosen AI provider — details below.

Replying to messages

Everything you can do from a message box.

The button

Click into a message box on the Messaging page or in a chat pop-up. ✨ AI Reply appears just above it. Click to draft; click again for a fresh take.

Keyboard shortcut

Prefer the keyboard? Press Alt + R while your cursor is in a message box to do exactly what the button does.

Goal, Ask & voice

Open ▾ to steer the reply: pick a goal, and add an optional Ask for just this draft — type it, or tap the 🎤 and dictate it.

Review in a panel

The draft lands in the box and in a panel where you can edit it, Copy it, or Insert into box again — nothing sends until you press Send.

Answers recruiter questions

It only states facts you saved in Settings (rate, W2/C2C, locations, availability). Anything it doesn't know, it offers to confirm or asks about instead of inventing.

Reads the whole thread

It replies to the latest message using earlier ones as context, so it stays on topic across a back-and-forth conversation.

Layout-change proof

If LinkedIn changes its page structure and the thread can't be parsed cleanly, it falls back to the raw page text around the box so you still get a draft.

Outreach from a profile

On any LinkedIn profile, the ✨ Draft message button (bottom-left) reads the profile and fills one of your templates.

Sharper matching

Add a role, or paste the job description, into the notes. It picks 2–3 skills only from your saved stack that best match the JD or the person's team and tech.

One send-from line

Email templates use the send-from address you set once in Settings, shown at the top of the draft so you know which inbox to send from.

Copy or insert

Use Copy message, Copy all (with subject and send-from), or Insert into LinkedIn box after you open Message or Add a note.

Safe placeholders

Anything the profile doesn't tell it — a referrer's name, a date — stays in [brackets] for you to fill, so nothing gets made up.

Get started

A one-time setup, then it just works on LinkedIn.

  1. Install Claude Code (recommended path).

    Install it from code.claude.com, open a terminal, run claude once and sign in with your Claude account. Prefer an API key instead? Skip to step 4.

  2. Install Node.js.

    Grab the LTS build from nodejs.org if node -v doesn't already print a version. The local helper needs it.

  3. Load the extension.

    Open chrome://extensions, turn on Developer mode, click Load unpacked, and pick the folder that directly contains manifest.json. On first install, this page opens automatically.

  4. Register the helper (once).

    Double-click nativehost\install.bat once. That's it — Chrome then launches Claude on demand, with no window to keep open and nothing running in the background. Prefer an API key? Skip this step entirely.

  5. Tell it about you.

    Click the toolbar icon to open Settings. Choose your provider (Claude subscription, or paste an Anthropic/OpenAI key), fill in your name, background, writing style, stack and send-from email, then click Save & test. The AI only states facts you provide here.

  6. Draft away.

    Refresh LinkedIn — a "LinkedIn AI Reply is on" message confirms it loaded. Click into a message or open a profile and press the ✨ button. Review, edit, and Send.

Privacy & what gets sent

Your settings, API keys, profile details and remembered conversations are stored only in your browser (chrome.storage.local). The extension never sends messages for you — it only drafts text and inserts it into the box.

To draft a reply, some data has to reach an AI model. What is sent, and to whom, depends on the provider you pick in Settings:

  • Claude subscription (default): your “About you” text and the open conversation or profile text are passed to a helper on your own machine, which runs Claude Code. Claude Code then sends that text to Anthropic under your Claude plan. Nothing goes to a server run by this extension.
  • Anthropic API key: the same text is sent directly from your browser to Anthropic (api.anthropic.com).
  • OpenAI API key: the same text is sent directly from your browser to OpenAI (api.openai.com).

In every case the data sent includes: your “About you”/background and style text, the other person’s messages in the open thread (or the profile text for outreach), and your remembered recap of recent exchanges with that person. It does not include your API key. Review each provider’s own privacy and data-retention terms.

API keys are stored in plaintext in chrome.storage.local, which is standard for Chrome extensions but means anything with access to your browser profile can read them. Prefer the Claude subscription path if you'd rather not store a key at all. Optionally keep your non-secret details in a git-ignored config.local.js so they survive a reinstall.

FAQ

Do I need an API key?

No. By default it uses your Claude subscription through Claude Code running on your computer, so there's no key and no extra cost beyond your plan. An Anthropic or OpenAI API key is an optional alternative.

Does it send messages automatically?

Never. It only writes a draft into the box. You read it, edit it, and press Send yourself — every time.

How long does a draft take?

Roughly 5–20 seconds with Claude Code, depending on your machine and the length of the thread.

Will it make up facts about me?

No. It only states facts written in Settings → "Background & preferences", and picks skills only from your saved stack. Missing details are left as [brackets] or turned into a question.

Does it remember my conversations?

It keeps a short, capped recap of your last few exchanges with each person, stored only in this browser. That recap is included in the prompt sent to your AI provider (see Privacy) so new drafts stay consistent with what you said before. You can wipe it with one click in Settings → Memory.

Can I dictate instead of typing?

Yes. Open the ▾ options under AI Reply and tap the 🎤 mic to speak your one-off Ask; it fills the field for you. The first time, allow microphone access for LinkedIn.

The reply misread the conversation — why?

LinkedIn may have changed its page layout. The extension then falls back to reading the raw page text around the message box; re-clicking usually gives a cleaner result.

Is this affiliated with LinkedIn or Anthropic?

No. It's an independent project that works with your own Claude or API access.
